# Face Portrait Cropper

Система для автоматического обнаружения лиц и создания портретов с расширенной областью обрезки.

## Возможности

- 🔍 **Обнаружение лиц** с использованием MTCNN
- 📐 **Расширение области** bounding box на заданный процент
- 🖼️ **Создание портретов** с оптимальным кадрированием
- 🔄 **Пакетная обработка** серий изображений
- 👥 **Многолицевые изображения** - создание портретов для каждого лица

## Установка

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Убедитесь, что у вас установлены необходимые модели MTCNN

## Использование

### Обработка одного изображения
```bash
python FacePortraitCropper.py -i input.jpg -o portrait.jpg --expand 0.2
```

### Пакетная обработка директории
```bash
python FacePortraitCropper.py -i ./input_folder/ -o ./output_folder/ --batch --expand 0.2
```

### Параметры командной строки

- `-i, --input` - путь к входному файлу или директории (обязательный)
- `-o, --output` - путь для сохранения результата (обязательный)
- `--expand` - процент расширения bounding box (по умолчанию: 0.2 = 20%)
- `--batch` - флаг для пакетной обработки директории

## Примеры
